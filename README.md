# douyin-sc · 抖音批量清理（Chrome 扩展）

网页抖音批量管理：取消喜欢、取消收藏、删除自己的作品。支持多账号、多轮清理直到清空。

> 仅用于管理**你本人授权**的抖音账号。请遵守抖音用户协议。删除 / 取消**不可恢复**。

## 安装（Chrome / Edge 扩展）

1. 打开 `chrome://extensions`
2. 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本仓库中的 `chrome-ext/` 文件夹
4. 打开并登录 [https://www.douyin.com/user/self](https://www.douyin.com/user/self)
5. 右下角出现 **dy-clean** 面板

更新脚本后，请在扩展页点 **重新加载**，并刷新抖音页面（面板标题应显示当前版本）。

## 使用

| 步骤 | 操作 |
|------|------|
| 1 | 点 **诊断当前页面**，确认能识别列表 |
| 2 | 勾选目标：喜欢 / 收藏 / 作品（作品默认不勾） |
| 3 | **不勾 live** → 开始清理 = **只统计，不删除** |
| 4 | 确认数量后勾选 **live 真删** → 输入确认短语 `确认清理` |

真删时会自动点弹窗中的 **「确认取消 / 确认删除」**，并**循环多轮直到清空**（无进展会自动停止，防卡死）。

## 多账号

退出登录 → 换账号登录 → 点面板「开始清理」即可，无需重装扩展。

## 目录

```text
chrome-ext/
  manifest.json   # MV3 扩展清单
  content.js      # 面板与批量清理逻辑
douyin-batch-clean.console.js   # 可选：控制台备用脚本
```

## 工作原理

```text
个人主页 → 作品/喜欢/收藏
  → 批量管理 → 全选
  → 取消喜欢 / 取消收藏 / 删除作品
  → 确认弹窗
  → 未清空则自动下一轮
```

定位以页面可见文案为主，降低改版后 class hash 失效的影响。

## 故障排查

| 现象 | 处理 |
|------|------|
| 没有面板 | 扩展是否启用；刷新扩展与页面；Console 是否有 `[dy-clean] chrome-ext` |
| 进入批量管理失败 | 先手动点到「喜欢/收藏」列表；点「诊断当前页面」看输出 |
| 只删了一部分 | 使用 v1.6+（多轮）；看是否提示「无进展」（可能风控） |
| 换号后无效 | 重新登录后刷新页面再跑 |
